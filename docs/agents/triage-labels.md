# Triage 标签

工程技能使用五类标准 Triage 角色。本文件将这些角色映射为本仓库 Issue 追踪器中的实际标签字符串。

| 技能中的角色 | 本仓库标签 | 含义 |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | 维护者需要评估该 Issue |
| `needs-info` | `needs-info` | 等待报告者补充信息 |
| `ready-for-agent` | `ready-for-agent` | 规格完整，可交给自主 Agent 实施 |
| `ready-for-human` | `ready-for-human` | 需要人工实施 |
| `wontfix` | `wontfix` | 不会处理 |

当技能提到某个角色（例如“应用可交由 Agent 的 Triage 标签”）时，使用本表对应的标签字符串。

如本仓库后续采用不同的标签命名，可直接修改右侧“本仓库标签”列。
